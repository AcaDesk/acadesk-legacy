# Acadesk — 학부모앱 · 학생앱 디자인 브리프

> **이 문서의 대상**: Acadesk를 처음 접하는 UI 디자이너
> **목적**: Acadesk가 어떤 SaaS이고 무슨 기능이 있는지 하나도 빠짐없이 이해한 뒤, **학부모앱**과 **학생앱**을 설계할 수 있도록 하는 것
> **읽는 순서 제안**: 1~4장(제품 이해) → 5~6장(도메인·전체 기능) → 7~11장(설계할 두 앱의 실제 콘텐츠) → 12~14장(디자인 규칙과 화면 제안)

---

## ⭐ 디자이너가 가장 먼저 알아야 할 3가지

1. **Acadesk는 한국 "학원(cram school)" 운영을 자동화하는 B2B SaaS다.** 지금까지 만들어진 것은 **학원 직원(원장·강사·조교)이 쓰는 웹 관리자 앱** 하나뿐이다. 학생·학부모는 이 시스템의 "대상"이지 "사용자"가 아니었다.

2. **학부모앱·학생앱은 아직 존재하지 않는다. 이번에 처음 설계하는 것이다.**
   - 기능 플래그상 `parentApp = inactive`(미출시), 학생용 전용 앱도 없음.
   - 현재 학부모의 유일한 접점은 **① 카카오 알림톡/문자** + **② 로그인 없이 열리는 리포트 링크 웹페이지**뿐이다.
   - 현재 학생의 유일한 접점은 **학원에 비치된 태블릿(키오스크)** 화면뿐이다.
   - 즉, 당신은 이 흩어진 접점들을 **제대로 된 앱 경험으로 새로 설계**하는 일을 맡았다. 아래 7~11장이 그 재료다.

3. **모든 UI는 한국어. 학원·학부모·학생이 쓰는 한국 교육 현장의 말투와 관례를 따른다.** (예: 학부모는 이름이 아니라 "○○ 어머니"로 부른다. 12장 참고.)

## 1. Acadesk란 무엇인가

**한 문장 정의**: Acadesk는 한국 학원을 위한 **멀티테넌트 SaaS 학원 관리 플랫폼**으로, 원장·강사·조교가 수작업 문서 없이 **출결·성적·리포트·상담·알림**을 자동화하고, 데이터 기반 피드백으로 학부모 신뢰와 재등록률을 높이며, 투두리스트로 학생의 자기주도 학습을 지원한다.

**비즈니스 목표 (제품이 존재하는 이유)**
- **운영 효율성**: 원장·강사가 수작업 문서 없이 출석·성적·리포트를 자동 관리 → "리포트 작성 시간 80% 단축"이 핵심 KPI
- **학부모 신뢰 강화**: 데이터 기반 피드백·리포트로 학부모 만족도와 **재등록률** 향상 → "학생 1명 이탈만 막아도 서비스 비용이 회수된다"는 가치 포지셔닝
- **학생 자기주도성**: 투두리스트 기반 학습 관리로 학습 동기·성취감 부여 (완료율 70% 목표)
- **확장성**: 단일 학원 → 다수 학원 → 지점·프랜차이즈로 확장 가능한 멀티테넌트 구독 모델

**타겟 시장**: 초기 핵심은 **중규모 학원(학생 30~150명)**. 행정 부담이 가장 크고 지불 의향이 높으며, 핵심 기능(출결·알림톡·성적)의 가치가 가장 명확히 전달되는 세그먼트.

**멀티테넌트 = 학원(Tenant) 단위 격리**: 하나의 Acadesk 안에 여러 학원이 있고, 각 학원의 데이터는 서로 완전히 분리된다. 학부모·학생은 **자기 학원의, 자기(자녀) 데이터만** 본다. 앱 설계 시 "내 학원 브랜딩(학원명·연락처)"이 화면 곳곳에 노출된다는 점을 전제로 한다.

## 2. 사용자 역할 5종

| 역할 | 한글 | 하는 일 | 앱 대상? |
|------|------|---------|----------|
| Owner | **원장** | 학원 전체 운영 총괄. 대시보드로 현황 파악, 투두 등록, 리포트 발송 승인. 전체 기능 접근. | 관리자 웹(기존) |
| Instructor | **강사** | 담당 학생 출결·성적 입력, 진도 코멘트, 투두 검증. | 관리자 웹(기존) |
| Assistant | **조교** | 출석·시험 입력 보조, 도서 대여. **개인정보(연락처) 접근 제한.** | 관리자 웹(기존) |
| **Parent** | **학부모/보호자** | 자녀의 출결·성적·리포트를 주/월 단위로 확인, 상담 요청. | **★ 학부모앱 (신규 설계 대상)** |
| **Student** | **학생** | 오늘의 과제 확인·완료 체크, 출석 체크, 본인 성적·진도 열람. | **★ 학생앱 (신규 설계 대상)** |

> 권한 원칙: 학생은 **본인 데이터만**, 학부모는 **자기 자녀 데이터만** 본다. 조교는 연락처 등 민감정보가 가려진다.

## 3. 현재 학부모·학생이 겪는 경험 (설계의 출발점)

앱이 없는 지금, 접점은 이렇게 작동한다. 이 세 가지가 새 앱이 흡수·승격시켜야 할 핵심 경험이다.

### 학생의 현재 경험 — 학원 태블릿(키오스크)
1. 학원에 도착 → 비치된 태블릿에서 **보호자 전화번호 뒤 4자리** 입력 → 본인 확인 → **등원하기** 터치
2. 로그인 후 개인 화면에서 **오늘의 과제(투두)** 확인 → 완료 체크
3. 모든 과제가 강사 **검증**까지 끝나면 "🎉 조기 퇴실 가능" 축하 화면
4. 집에 갈 때 → 태블릿에서 **하원하기** 터치

### 학부모의 현재 경험 — 카카오 알림톡 + 리포트 링크
1. 자녀가 등원하면 카카오톡으로 "○○ 학생이 17:30에 등원하였습니다" 알림 수신
2. 결석/성적/상담/리포트 등 이벤트마다 알림톡 수신 (전체 21종, 10장 참고)
3. 월말/주간이면 "학습 리포트가 준비되었습니다 + [링크]" 수신 → **링크를 누르면 로그인 없이** 자녀의 성적 그래프·출석률·강사 코멘트가 담긴 웹 리포트가 열림
4. 링크는 기본 **7일 후 만료** → 만료 시 "학원에 재발급 요청" 안내

### 이 문서가 제안하는 미래 (14장 IA에서 구체화)
- **학생앱** = 키오스크 경험의 개인화·모바일화 (오늘의 과제 + 출석 + 내 성적/진도 + 성취 게이미피케이션)
- **학부모앱** = 흩어진 알림톡 + 리포트 링크를 하나의 자녀 대시보드로 통합 (실시간 등하원·출결·성적 추이·리포트 보관함·상담 요청)

## 4. 제품의 설계 원칙 (기존 관리자 앱에서 이어받을 철학)

1. **역할 기반 접근** — 각 역할은 자기에게 필요한 것만 본다.
2. **대시보드 우선** — 로그인 직후 "가장 중요한 현황"이 한눈에. (학부모앱이면 "오늘 우리 아이" 상태, 학생앱이면 "오늘 할 일".)
3. **학생 중심 통합 뷰** — 한 학생에 대한 출결·성적·과제·상담·교재·리포트가 한 곳에 모인다. (학부모앱의 자녀 화면이 이 원칙을 그대로 계승.)
4. **입력 효율성** — 반복 작업은 빠른 폼/체크로. (학생앱의 과제 체크, 출석 체크가 여기에 해당.)
5. **비교 지향** — 거의 모든 수치는 "전월 대비 ▲▼", "반 평균 대비"로 보여준다. 단일 숫자보다 변화·맥락을 강조.

## 5. 도메인 개념 사전 (디자이너 필수 용어)

Acadesk의 모든 화면은 아래 개념 위에 만들어진다. **학생(Student)이 중심 허브**이고, 나머지가 학생에 매달린다.

```
학원(Tenant)
 └─ 학생(Student) ★중심
     ├─ 보호자(Guardian)          ── 다대다, 학생당 "주 보호자" 1명
     ├─ 반/수업(Class)             ── 수강등록(Enrollment)으로 연결, 강사·과목 소속
     ├─ 등원 스케줄(Schedule)      ── 요일별 등원시간 → 지각 판정 기준
     ├─ 출석(Attendance)           ── 세션별 출결
     ├─ 시험 성적(ExamScore)       ── 시험(Exam)별 점수, 재시험 포함
     ├─ 과제(Todo/Homework)        ── 원내 자율학습 / 집 숙제
     ├─ 상담(Consultation)         ── 학부모·학생 상담 기록
     ├─ 교재(Textbook)             ── 배부·진도·결제
     ├─ 도서 대여(Library Loan)    ── 원서/도서 대여·반납
     ├─ 상벌점(Point)              ── 상점(+)/벌점(-)
     ├─ 리포트(Report)             ── 주간/월간 학습 리포트
     └─ 활동 타임라인(ActivityLog) ── 위 모든 활동의 통합 연대기
```

**핵심 엔티티 요약**

| 개념 | 학부모·학생 앱에서의 의미 | 주요 정보 |
|------|--------------------------|-----------|
| **학생(Student)** | 앱의 주인공. 학부모앱은 "자녀", 학생앱은 "나". | 학번, 이름, 학년, 학교, 프로필 사진, 입회일, 등하원 방법 |
| **보호자(Guardian)** | 학부모앱 사용자 본인. 자녀 여러 명 연결 가능(형제). | 이름, 전화, 관계(부/모/조부모…), 권한 플래그(리포트 조회·알림 수신·픽업 등) |
| **반/수업(Class)** | "우리 아이가 듣는 수업" | 반 이름, 담당 강사, 과목, 시간표, 정원 |
| **출석(Attendance)** | 등하원·출결. 학생앱은 체크 주체, 학부모앱은 실시간 확인. | 상태(출석/지각/결석/조퇴/사유결석), 등원·하원 시각, 지각 분 |
| **시험 성적(ExamScore)** | 리포트·성적 화면의 핵심 데이터 | 원점수, 만점, **백분율(0~100 보편 지표)**, 반 평균, 재시험 여부 |
| **과제(Todo)** | 학생앱의 "오늘 할 일" | 제목, 과목, 마감, 예상 소요시간, 상태(대기→완료→검증) |
| **리포트(Report)** | 학부모앱의 대표 콘텐츠 | 주간/월간, 성적·출석·과제·성장그래프·강사 코멘트 스냅샷 |
| **상벌점(Point)** | 게이미피케이션 소재 | 상점(+)/벌점(-), 사유 |

## 6. 전체 기능 지도 (관리자 웹앱 — 맥락 이해용)

학부모·학생 앱이 보여줄 데이터가 **어디서 만들어지는지** 알기 위한 지도다. (아래는 원장·강사가 쓰는 기존 웹앱의 모듈 전체 목록. ★ 표시가 학부모·학생 앱과 직접 연결됨.)

| 모듈 | 상태 | 하는 일 | 앱 연결 |
|------|------|---------|---------|
| 대시보드 | 운영중 | 학원 전체 현황(출석·성적·과제 완료율·알림) 위젯 | 앱 대시보드의 원형 |
| 캘린더 | 운영중 | 수업·시험·행사·상담 통합 일정 | ★ 학부모·학생 일정 |
| **학생 관리** | 운영중 | 학생 CRUD, 등록 마법사, 엑셀 일괄등록, 진급 관리, 형제 연결, 상벌점 | 앱의 학생 프로필 원천 |
| **보호자 관리** | 운영중 | 학부모 정보, 학생-보호자 연결, 권한 플래그 | ★ 학부모앱 계정 원천 |
| **출석 관리** | 운영중 | 수업별 출석 체크(웹/모바일/키오스크), 결석자 일괄 연락 | ★ 등하원·출결 |
| 수업 관리 | 운영중 | 반 편성, 시간표, 학생 배정 | ★ 시간표 |
| **TODO & 숙제** | 운영중 | 원내 자율학습·집 숙제 배정→완료→검증, 주간 플래너, 통계 | ★ 학생앱 핵심 |
| **성적 & 시험** | 운영중 | 시험 등록, 성적 일괄 입력, 재시험 관리, 시험 템플릿 | ★ 성적 화면 |
| 교재 & 자료 | 운영중 | 교재 목록, 배부, **진도 기록** | ★ 교재 진도 |
| 도서 대여 | 운영중 | 원서/도서 대여·반납, 연체 알림 | ★ 도서 현황 |
| **상담 관리** | 운영중 | 신규 입회/재원생 상담 기록, 후속조치 | ★ 상담 요청·결과 |
| **리포트 관리** | 운영중 | 주간/월간 학습 리포트 생성·발송, 대량 발송 마법사, 열람 추적 | ★ 학부모앱 핵심 |
| **알림/메시지** | 운영중 | 알림톡·SMS 발송 이력·통계·템플릿 | ★ 앱 알림의 원천 |
| 직원 관리 | 운영중 | 직원 초대·권한(원장 전용) | — |
| 설정 | 운영중 | 학원 정보, 과목, 카카오 채널 연동, 이벤트 알림 구독, 메시지/리포트 템플릿, **키오스크** | 앱 브랜딩·알림 정책 |

| AI 분석 | 미출시 | — | 향후 |

## 7. ★ 학생앱 상세 — 현재 키오스크 화면 (설계의 원본 재료)

학생앱이 개인화·모바일화할 **현재 키오스크 UI**를 화면 단위로 정리한다. 톤: 큰 터치 타깃, 숫자 키패드, 아바타, 축하 애니메이션(모션 트랜지션 사용 중).

### 7-1. 출석 체크 화면 (등하원)
- **큰 시계·날짜** 상단 표시 (한국어 로케일)
- **숫자 키패드 + PIN 점 표시**
- 플로우(상태 머신): `입력 → (형제면)선택 → 확인 → 성공`
  - **입력**: "보호자 전화번호 뒷 4자리를 입력해주세요" → 4자리 입력 시 자동 조회
  - **선택**(같은 번호에 형제가 여러 명일 때만): "본인을 선택해주세요 / 같은 번호로 등록된 학생이 여러 명입니다" → 이름·학년·현재 상태 배지가 있는 카드
  - **확인**: 큰 아바타(이름 첫 글자), 이름, 학년, 현재 상태 배지 + **[등원하기]** / **[하원하기]** 버튼 (현재 상태에 따라 비활성)
  - **성공**: 초록 체크 애니메이션 → "등원/하원 처리 완료 / ○○님, 수고하셨습니다!" → **3초 후 자동 초기화** 프로그레스 바
- 상태 배지: `미등원`(회색) / `등원 중`(초록) / `하원 완료`(파랑)
- 우상단 **관리자 종료(X)** → 관리자 PIN 입력 → 대시보드

### 7-2. 오늘의 과제 화면 (`/kiosk` 메인) — 학생앱의 심장
로그인 후 개인 화면. **오프라인 동작 지원**(네트워크 없어도 체크 후 나중에 동기화).

- **헤더 카드**: "○○년 ○월 ○일 ○요일 / ○○님(학번) / 오늘도 열심히 공부해요! 👋"
- **진행률 카드 "오늘의 학습 목표"**: "N개 중 M개 완료" 또는 "✨ 모든 과제를 완료했어요!", 큰 퍼센트 + 프로그레스 바. 전부 완료했지만 미검증이면 → "선생님께 가서 과제 검증을 요청하세요!"
- **과제 리스트** — 각 카드:
  - 체크박스(완료 토글, 검증되면 잠김), 제목, **과목 배지**, **예상 소요시간 배지("N분")**
  - 강사 피드백 노트("💬 선생님 피드백: …", 노랑)
  - "검증 완료" 배지
  - 상태별 색: 검증완료(초록) / 완료(파랑) / 대기
  - 빈 상태: "오늘 배정된 과제가 없습니다."
- **과제 상세 다이얼로그**(탭 시): 상태 배지, 마감일, 예상 소요시간, 상세 설명, 선생님 피드백, [완료하기]/[완료 취소]
- **축하 오버레이**(모든 과제 검증 완료 시): "🎉 축하합니다! / 모든 과제가 검증되었습니다! / 조기 퇴실 가능 / 오늘 정말 수고했어요! 선생님께 조기 퇴실 승인을 받으세요." + 🏆 [확인]

> **핵심 메커니즘 — 완료 ≠ 검증**: 학생이 과제를 **체크(completed)** 해도, 강사가 **검증(verified)** 해야 최종 인정된다. 학생은 스스로 검증할 수 없다. 이 2단계가 "조기 퇴실"이라는 보상으로 연결되는 것이 학생 동기부여의 핵심 UX다.

### 7-3. 학생앱이 추가로 열람 가능한 것 (제품 기획상)
학생은 본인의 **성적, 교재 진도, 도서 대여 현황**도 열람할 수 있어야 한다(기획 문서 근거). 현재 키오스크엔 없지만 학생앱에서 설계 대상.

## 8. ★ 학부모앱 상세 (1) — 알림톡/문자 메시지

## 9. ★ 학부모앱 상세 (2) — 학습 리포트 (대표 콘텐츠)

리포트는 학부모 경험의 **핵심 aha-moment**다. 현재는 "알림톡 링크 → 로그인 없는 웹페이지"로 제공되며, 학부모앱에서는 **자녀별 리포트 보관함 + 상세 뷰어**로 승격되어야 한다.

### 리포트란
학생 1명의 특정 기간(주간/월간) 학습 스냅샷. 생성 시점의 데이터를 그대로 저장해 **언제 다시 봐도 동일**하다.

### 리포트 상세 화면 구성 (위→아래 순서)
1. **학원 헤더** — 학원명, 📞 전화, 📍 주소, ✉️ 이메일
2. **학생 정보** — 이름(학번), 학년
3. **KPI 카드 3개** — `평균 점수`(전월 대비 ▲▼), `출석률`(출석/전체 일수), `과제 달성률`(완료/전체)
4. **과목별 KPI 카드** — 과목마다 현재 점수 + 전월 대비 델타
5. **막대차트 "과목별 성적"** — 내 점수 (+ "반 평균 보기" 토글)
6. **출석 히트맵 "월별 출석 캘린더"**
7. **선그래프 "성적 추이"** — 최근 3개월 평균 변화 (내 점수 vs 반 평균 토글)
8. **선그래프 "과목별 성적 변화"** — 시험별 과목 점수 추이
9. **아코디언 상세** — "과목별 점수 상세"(과목/점수/전월 대비/합계 행), "과목별 시험 상세"(시험 날짜·이름·백분율, 재시험률>0이면 표시)
10. **강사 종합 코멘트** — 4개 구조화 필드: 📝 총평 / ✨ 잘한 점 / 📈 보완할 점 / 🎯 다음 달 목표

### 리포트 하단(공유 뷰) 정보
"리포트 정보" 카드: 생성일, "수신자: ○○ 님", 링크 만료일, 학원 📞/✉️, 저작권 표기.

### 리포트에 대한 중요한 사실 (디자인 제약)
- **AI가 아니다.** 강사 코멘트는 템플릿 기반(조건에 따라 추천 문장 제공) + 강사 수기 작성. 앱 카피에서 "AI 분석"이라 표현하면 안 됨.
- 리포트는 학원이 **개별 항목을 끄고 켤 수 있다** (예: 출석률 숨김, 출석 캘린더 숨김). 학부모 뷰는 학원이 설정한 그대로 노출 → 앱 뷰어는 **섹션 유무가 가변적**임을 전제로 유연하게.
- 현재 리포트에는 **독서/도서·투두 상세는 미포함**(성적·출석·과제완료율·코멘트 중심). 단, 기획상 학부모앱은 교재 진도·도서·투두 수행률까지 보여주는 것을 지향하므로, 확장 섹션 자리를 남겨두면 좋다.
- **열람 추적**: 학부모가 링크를 열면 학원이 "열람 확인"을 본다. 앱에서도 "읽음" 개념이 이어질 수 있다.

### 리포트 외 학부모가 하는 행동 (기획상)
- 리포트 **PDF 다운로드** (현재 공유 링크에선 비활성, 앱에선 검토 대상)
- **상담 예약/요청** — 학부모가 앱에서 학원에 상담을 요청하는 흐름(신규 설계 여지)

## 10. ★ 학부모앱 상세 (3) — 자녀 대시보드에 모을 데이터

학부모앱의 홈은 "오늘 우리 아이" 통합 뷰가 되어야 한다. 관리자 앱의 **학생 상세 통합 뷰**를 학부모용으로 재구성한 것으로 볼 수 있다. 모을 수 있는 데이터:

- **오늘의 상태**: 등원/하원 시각, 오늘 출결 상태
- **출결 요약**: 이번 달 출석률, 지각·결석 횟수, 월별 출석 캘린더(히트맵)
- **성적**: 최근 시험 성적, 과목별 추이, 반 평균 대비, 재시험 현황
- **과제**: 오늘/이번 주 과제 완료율, 검증 현황
- **교재 진도**: 교재별 진도율(페이지·%)
- **도서 대여**: 대여 중 도서, 반납 예정일, 연체 여부
- **상벌점**: 상점/벌점 내역과 잔액
- **상담**: 예정된 상담, 최근 상담 결과
- **리포트 보관함**: 지난 주간/월간 리포트 목록
- **알림 피드**: 8장의 이벤트 알림 이력
- **형제 전환**: 자녀가 여럿이면 자녀 간 스위칭 (보호자-학생은 다대다)

## 11. 학습 활동 상세 (앱에 그대로 반영되는 규칙들)

학부모·학생 앱이 데이터를 정확히 표현하려면 알아야 할 학사 규칙.

### 출석
- 상태: **출석 / 지각 / 결석 / 조퇴 / 사유결석**
- 소스: `키오스크`(학생 셀프) vs `수동`(강사 입력) — 앱에서 출처를 구분 표시할 수도 있음
- 등원·하원 각각 시각 기록. 등원 스케줄 기준으로 **지각 분** 계산
- 결석/지각엔 사유 코드(병결·학교행사·교통체증 등), 일부는 증빙 필요
- 부가 상태: **자습(is_self_study)**, **보강(is_makeup_class)**

### 성적·시험
- **백분율(0~100)이 보편 지표.** 색 구간 관례: 90+ / 70+ / 70 미만 (합격 기준 기본 70점)
- 시험 카테고리: 월말평가·주간평가·Quiz·쪽지시험·레벨테스트·모의고사 등 (학원이 편집 가능)
- **재시험(retest)**: 합격 점수 미달 시 자동으로 재시험 대상. 재시험 횟수 카운트, 리포트에 "재시험률" 지표. 재시험 시험명은 `[재시험] 원래시험명`
- 성적 상태: 미응시/대기/제출/재시험필요/재시험면제
- 모든 수치는 **전월 대비 ▲▼**, **반 평균 대비**로 비교 표시

- 상점(+)/벌점(-)과 사유. 예: 개근상 +10, 우수성적 +15 / 지각 -5, 무단결석 -10 → 게이미피케이션 소재

## 12. 한국 학원 도메인 특수 개념 (반드시 UI에 반영)

| 개념 | 설명 | 디자인 반영 |
|------|------|-------------|
| **호칭 관례** | 학부모는 이름이 아니라 **"○○(자녀 이름) 어머니/아버지"**로 부른다. 예: "이유빈 어머니". 본명은 부가정보. | 학부모앱 인사·표시는 자녀 이름 기반 호칭을 우선 |
| **재시험(retest)** | 기준 미달 시 다시 시험. 한국 학원의 성실도·성취 관리 문화의 핵심. | 성적 화면에서 재시험을 "실패"가 아닌 "보완 기회"로 긍정 프레이밍 |
| **자율학습 vs 숙제** | 학원 안에서 하는 과제와 집에서 하는 숙제를 구분 | 학생앱에서 둘을 분리 표시 |
| **조기 퇴실** | 과제를 다 하고 검증받으면 일찍 하원 가능 → 학생의 최고 보상 | 학생앱 게이미피케이션의 정점(🎉 축하) |
| **등원/하원** | "출석/퇴실"이 아니라 등원/하원 용어 사용 | 버튼·알림 문구 |
| **주 보호자** | 학생당 대표 보호자 1명. 키오스크 전화 인증의 기준. | 학부모앱에서 주/부 보호자 권한 차이 고려 |
| **반 평균 / 전월 대비** | 절대 점수보다 상대·변화를 중시 | 모든 수치에 비교 맥락 |

## 13. 디자인 요구사항·제약

- **언어**: 전면 한국어. 문구는 존중하고 따뜻한 학부모/학생 톤.
- **모바일 우선**: 학부모앱·학생앱 모두 스마트폰이 1차. (현 리포트 공유 뷰도 모바일 우선으로 되어 있음.)
- **학생앱 = 태블릿/모바일 겸용**: 큰 터치 타깃, 숫자 키패드, 아바타, 축하 애니메이션 톤 계승. 학원 공용 태블릿(키오스크)과 개인 모바일 두 맥락 모두 고려.
- **게이미피케이션**: 학생앱은 과제 완료·상점·조기 퇴실을 성취/보상으로. 이미 키오스크에 🎉·🏆 톤 존재 → 일관 유지.
- **학원 브랜딩 가변**: 화면 곳곳에 "그 학원의" 이름·연락처·색이 들어감(멀티테넌트). 하드코딩 금지, 브랜딩 슬롯 설계.
- **인증 UX (중요)**:
  - 학생: 현재 전화 뒤 4자리 / PIN 기반. 간결하되 브루트포스 방어(잠금·레이트리밋) UX 필요.
  - 학부모: 현재는 링크 소유가 곧 인증. 신규 앱은 제대로 된 로그인/계정 설계가 필요(보호자-자녀 연결, 형제 스위칭 포함). `guardians.user_id`가 향후 로그인 연결 고리.
- **오프라인**: 학생앱 과제 체크·출석은 오프라인 후 동기화되는 흐름 존재 → "동기화 대기" 상태 표현 필요.
- **접근성/색**: 상태값마다 이미 배지 색 관례가 있음(출석=초록·지각=노랑·결석=빨강 등). 11장 상태 어휘를 색 시스템으로 정리 권장.

## 14. 화면 목록(IA) 초안 — 설계 시작점

아래는 위 재료를 종합한 **제안**이다. 확정안이 아니라 디자이너의 출발점으로 삼는다.

### 학생앱 (Student App)
1. **로그인** — 이름 검색 → 전화 뒤 4자리/PIN (공용 태블릿 & 개인 모바일 대응)
2. **홈 "오늘"** — 오늘 할 일(과제) 진행률 + 등하원 상태 + 축하/조기퇴실
3. **출석 체크** — 등원/하원 (키오스크 모드)
4. **과제** — 오늘/이번 주, 자율학습·숙제 구분, 완료 체크, 강사 피드백/반려 사유, 검증 상태
5. **내 성적** — 최근 시험, 과목별 추이, 재시험 현황(긍정 프레이밍)
6. **내 진도·도서** — 교재 진도율, 대여 중 도서·반납일
7. **내 성취** — 상벌점, 배지/게이미피케이션
8. **알림**

### 학부모앱 (Parent App)
1. **로그인/온보딩** — 계정, 자녀 연결
2. **홈(자녀 대시보드)** — 오늘 등하원·출결, 이번 달 출석률, 최근 성적 요약, 이번 주 과제 완료율, 최근 알림 (+ 자녀 스위칭)
3. **출결** — 월별 출석 캘린더(히트맵), 지각·결석 내역·사유
4. **성적** — 과목별 점수·추이, 반 평균 대비, 재시험 현황
5. **리포트 보관함** — 주간/월간 리포트 목록 → **리포트 상세 뷰어**(9장 구성) → PDF/공유
6. **과제·학습** — 과제 완료율, 교재 진도, 도서 대여
7. **상담** — 예정/지난 상담, **상담 요청**
8. **알림 센터** — 이벤트 피드(카테고리별)
9. **설정** — 알림 수신, 자녀 관리, 학원 연락처
10. (향후) **학원비/결제**

## 부록 B. 알아두면 좋은 사실

- **채널**: 학부모 메시지는 카카오 **알림톡** 우선, 실패 시 **SMS/LMS** 대체. 앱 도입 후엔 **앱 푸시**가 1차 채널 후보.
- **리포트 발송 단위**: 학원은 여러 학생 리포트를 **한 번에**(대량 발송 마법사) 생성·발송한다. 학부모는 자기 자녀 것만 받는다.
- **활동 타임라인**: 시스템은 학생의 모든 활동(시험·과제·출결·상담·리포트·도서·상벌점·입퇴원)을 단일 연대기로 자동 기록 → 학부모앱 "자녀 활동 히스토리" 피드로 활용 가능.
- **미출시 기능**: 학원비/결제, AI 분석은 아직 없음. 앱 IA에 자리만 남기고 지금 구현 대상은 아님.
