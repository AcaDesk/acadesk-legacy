# Batch Workbench 통합 체크리스트 (2안)

작성일: 2026-02-22  
범위: 리포트/코멘트/전송 대량 작업 UX 통합

## 1. 사전 정렬

- [ ] 통합 대상 기능 확정 (`report`, `comment`, `send`)
- [ ] 기존 각 화면의 필수 입력/검증 규칙 목록화
- [ ] 기존 API 재사용 범위와 신규 API 필요 범위 합의
- [ ] 권한 모델(실행/조회/재시도) 확정
- [ ] 성공 지표 baseline 수집 (완료시간, 실패율, 첫 성공률)

## 2. 정보 구조/라우트

- [ ] `/batch` 홈 라우트 생성
- [ ] `/batch/new/:draftId/*` wizard 라우트 생성
- [ ] `/jobs`, `/jobs/:jobId` 라우트 생성
- [ ] 기존 `/reports`, `/comments`, `/messages`에서 실행 진입 링크 연결
- [ ] 뒤로가기/새로고침 시 draft 복구 정책 반영

## 3. Wizard 공통 프레임

- [ ] `WizardLayout`, `WizardStepper` 구현
- [ ] 5단계 고정 플로우 구현
- [ ] `WizardStepGuard`로 단계 접근 제어
- [ ] 단계별 저장/불러오기(autosave) 구현
- [ ] 단계 이동 시 유효성 검사 및 에러 표시 구현

## 4. Step 1 대상 선택

- [ ] 공통 필터 패널 구현 (학년/반/상태/태그)
- [ ] 검색 및 다중 선택 테이블 구현
- [ ] 선택 요약 패널 구현 (선택/제외/총계)
- [ ] 대상 0건 시 다음 단계 차단
- [ ] 최근 선택/자주 쓰는 조건 불러오기(있다면) 연결

## 5. Step 2 작업 선택

- [ ] 작업 카드 3종 구현
- [ ] 선택 작업에 따른 예상 처리량/시간 표시
- [ ] 작업 미선택 시 다음 단계 차단

## 6. Step 3 옵션 설정

- [ ] 공통 옵션 섹션 구현 (우선순위/예약/실패 정책)
- [ ] 리포트 옵션 폼 구현
- [ ] 코멘트 옵션 폼 구현
- [ ] 전송 옵션 폼 구현
- [ ] 옵션 변경 시 draft patch 저장

## 7. Step 4 검토

- [ ] 영향 요약 카드 구현 (총 대상/작업별 처리 건수)
- [ ] 샘플 미리보기 5건 구현
- [ ] 리스크 경고 리스트 구현
- [ ] blocking risk 발생 시 실행 버튼 비활성화
- [ ] dry-run 결과 표시(도입 시) 연결

## 8. Step 5 실행/결과

- [ ] 실행 API 연동 (`execute`)
- [ ] 중복 실행 방지 (idempotency key + 버튼 잠금)
- [ ] 진행률 UI 구현 (total/processed/success/failed)
- [ ] 실패 사유 그룹 표시 구현
- [ ] `실패건만 재시도` 동작 구현
- [ ] `실패 목록 다운로드(csv)` 구현

## 9. Job 센터

- [ ] 이력 목록 필터 구현 (종류/상태/기간/실행자)
- [ ] 상태 뱃지 표준화 (`queued`, `running`, `partial_failed`, `succeeded`, `failed`)
- [ ] Job 상세 헤더/메트릭 구현
- [ ] 에러 상세 목록과 재시도 가능 여부 표시
- [ ] 재시도 후 상태 갱신 및 이벤트 로깅

## 10. API/서버

- [ ] `batch-drafts` 생성/조회/수정 API 구현
- [ ] `review` API 구현 (영향/샘플/리스크 반환)
- [ ] `execute` API 구현 (권한 재검증 포함)
- [ ] `jobs` 조회/상세 API 구현
- [ ] `retry-failed`/`errors.csv` API 구현
- [ ] 감사 로그 필드(실행자, 시각, 대상 수, 옵션 스냅샷) 저장

## 11. 권한/안전성

- [ ] 화면 레벨 접근 제어
- [ ] 서버 레벨 권한 재검증
- [ ] 재시도 가능한 오류만 허용
- [ ] 대량 실행 상한선/Rate limit 검토
- [ ] 취소/중단 정책 정의 및 반영

## 12. 품질 보증

- [ ] 단위 테스트: Step Guard/검증 규칙

- [ ] 회귀 테스트: 기존 리포트/코멘트/전송 관리 화면 영향 확인
