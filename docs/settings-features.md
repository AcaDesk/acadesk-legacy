# 설정 페이지 기능 목록

| 메뉴 | 경로 | 하위 탭/섹션 | 주요 기능 |
|------|------|-------------|-----------|
| **일반** | `/settings` | 시스템 정보 | 버전, 학원명, 플랜, 마지막 백업일 표시 |
| | | 도움말 및 지원 | 사용자 가이드 / FAQ / 고객 지원 / 피드백 링크 |
| | | 위험 구역 | 모든 데이터 초기화, 계정 삭제 (UI만, 미구현) |
| **학원 정보** | `/settings/academy` | 기본 정보 | 학원명, 사업자등록번호, 대표 전화·이메일, 주소, 웹사이트 수정 |
| | | 시스템 설정 | 시간대(Asia/Seoul 고정), 통화(KRW 고정), 학원 ID, 가입일 표시 |
| **과목 관리** | `/settings/subjects` | 과목 목록 | 과목명·코드·색상·설명·활성 상태·수업 수 조회, 검색 및 상태 필터 |
| | | 과목 CRUD | 과목 추가 / 수정 / 삭제 (삭제 시 연결 수업에서 과목 정보 제거) |
| **알림 서비스 연동** | `/settings/messaging-integration` | API 설정 | 메시징 서비스 선택 (알리고 / 솔라피 / NHN Cloud 준비 중) |
| | | | API 인증 정보 입력·저장 (API Key, Secret, 발신번호) |
| | | | 솔라피 연결 테스트 (잔액 확인) |
| | | | 테스트 메시지 발송 → 인증 |
| | | | 서비스 활성화/비활성화 토글 |
| | | | 설정 삭제 |
| | | 카카오 채널·템플릿 | 카카오 채널 연동 등록 / 상태 확인 / 연동 해제 |
| | | _(솔라피 인증 후 활성화)_ | 알림톡 온보딩 플로우 (공용 템플릿 자동 등록) |
| | | | 알림톡 템플릿 목록 조회 / 추가 / 수정 / 검수 상태 확인 |
| | | 이벤트 알림 | 이벤트별 자동 알림 구독 설정 (출결·상담·과제 등) |
| | | _(카카오 채널 연동 후 활성화)_ | |
| **메시지 템플릿** | `/settings/message-templates` | 템플릿 목록 | SMS/알림톡 템플릿 조회 (분류별: 출결·학원비·리포트·상담·과제·이벤트·일반) |
| | | | 템플릿 추가 / 수정 / 삭제 |
| | | | 변수 자동 추출 미리보기 (`{학생이름}`, `{날짜}` 등) |
| | | 통계 | 총 템플릿 수, 출결·학원비·리포트 템플릿 수 요약 |
| **키오스크** | `/settings/kiosk` | 기기 연결 상태 | 현재 기기의 키오스크 연결 여부 확인, 키오스크 실행, 기기 연결 초기화 |
| | | 관리자 종료 PIN | 키오스크 종료용 4자리 PIN 설정 (기본값: 9999) |
